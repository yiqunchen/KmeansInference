# Simulation code — more-powerful k-means selective inference

Experiments for the **union** ("more powerful") test for a difference in means
between k-means clusters, and its unknown-variance extension. The package itself
(`R/`) exports the known-variance method; everything here in `sims/` is the
experiment / research code.

All scripts are run from the **package root** with `Rscript sims/<file>.R`.
Outputs go to `sims/results/` (git-ignored — regenerated by the code).

## Setup

```r
# install the package (from the repo root)
R CMD INSTALL .                       # or: devtools::install()
# R deps used by the sims:
install.packages(c("intervals", "ggplot2", "gridExtra", "parallel"))
```

`parallel` ships with R. Figures also use `gridExtra`/`grid`.

## Method map (what is valid)

| test | variance | status | code |
|---|---|---|---|
| **union** (condition on the two tested clusters; more powerful) | known σ | **valid + more powerful** ✓ | `KmeansInference::kmeans_inference_union` (package) |
| path (original Chen–Witten) | known σ | valid | `KmeansInference::kmeans_inference` |
| path | unknown σ | valid (Yun–Barber F-pivot) | `unknown_var_union.R` |
| **union** | unknown σ | **valid, on the R-fiber** ✓ | `kmeans_union_unknownvar.R` (numerical), `kmeans_union_unknownvar_exact.R` (exact, any K) |
| ~~union, unknown σ, via φ-remap~~ | unknown σ | **INVALID (anti-conservative) — removed** | — |

Key point: the unknown-variance union must be computed **on the F-pivot's own
coordinate** (the R-fiber `x'(r)`), not by remapping the known-σ φ-fiber set.
The exact solver computes the truncation set in closed form (quartic-on-circle)
for **any K**, replacing Yun–Barber's importance sampling for K>2.

## Files

**Infrastructure**
- `checkpoint.R` — interrupt-safe incremental saving (atomic per-unit flush + resume). Crash-tested.
- `sweep_harness.R` — one parameter "cell" → per-method summary (`run_cell`). Geometry, balance, iso/genCov, detection + conditional power, known + unknown-variance columns.
- `sweep_run.R` — checkpointed driver + the parameter grids (tiers: `smoke`/`standard`/`full`/`cw`). **Resumable.**
- `house_style.R` — shared ggplot theme + palette (matches `../distributional-ppi`).

**Methods (sourced by the harness / tests)**
- `unknown_var_union.R` — unknown-variance **path** p-value (Yun–Barber F-pivot, post-processing of a fit).
- `kmeans_union_unknownvar.R` — **numerical** R-fiber union/path (bisection-refined arc boundaries; ~4s/call).
- `rfiber_exact.R` — **exact** solver, 7 modular pure functions (margins = quadratic-forms-on-the-circle = quartics).
- `kmeans_union_unknownvar_exact.R` — exact union/path via the arc-sweep (zero Monte Carlo; ~25s/call).

**Unit tests** (run these first to verify the exact solver)
- `test_rfiber_exact.R` — 14 tests of the primitives (vs ground truth).
- `test_path_arc.R` — 18 tests of the assembler (vs deterministic Lloyd).

**Validation** (calibration under the null)
- `validate_Rfiber.R` — numerical R-fiber union calibrates (K=3 global null).
- `validate_exact.R` — exact R-fiber union calibrates.

**Analysis**
- `power_type1_union_vs_path.R` — known-variance Type-I + power, union vs path vs naive.
- `union_multiplicity.R` — effective number of high-probability regions (M_eff ≈ 1) and "wasted exploration".

**Figures** (read from `sims/results/`)
- `plot_power_type1.R`, `plot_unknown_var.R`, `plot_standard_sweep.R`,
  `plot_cw.R`, `plot_cw_typeI.R`, `plot_cw_power.R`

## Reproduce everything — exact steps

Run from the package root. `<ncores>` = parallel chunks (use cores−1). Every
sweep is checkpointed: **re-run the identical command to resume**; append
`finalize` to (re)build `summary.csv` from whatever chunks exist.

```bash
# ---- 0. one-time setup ----------------------------------------------------
R CMD INSTALL .
Rscript -e 'install.packages(c("intervals","ggplot2","gridExtra"))'

# ---- 1. verify the code (~1 min) ------------------------------------------
Rscript sims/test_rfiber_exact.R          # exact-solver primitives  -> 14/14
Rscript sims/test_path_arc.R              # exact-solver assembler    -> 18/18
Rscript -e 'library(testthat); library(KmeansInference); test_dir("tests/testthat")'  # 54

# ---- 2. known-variance Type I + power (union vs path vs naive) ~10 min -----
Rscript sims/power_type1_union_vs_path.R 200 100      # -> results/power_type1_*.rds
Rscript sims/plot_power_type1.R                       # -> results/power_type1.{pdf,png}

# ---- 3. broad sweep: n=60, k / genCov / unbalanced extensions ~1 h ---------
Rscript sims/sweep_run.R standard 7 50 sims/results/sweep_standard
Rscript sims/sweep_run.R standard 7 50 sims/results/sweep_standard finalize
Rscript sims/plot_standard_sweep.R                   # -> results/standard_sweep.{pdf,png}

# ---- 4. Chen-&-Witten-faithful sweep: n=90 ~5 h ---------------------------
#   Type I (global null) q in {2,10,50,100} @1000 reps;
#   power q in {2,10,50} x delta=1..8 @sigma=1; detection + conditional power;
#   known-variance union AND valid unknown-variance (R-fiber) union columns.
Rscript sims/sweep_run.R cw 7 50 sims/results/sweep_cw          # (resume: re-run this line)
Rscript sims/sweep_run.R cw 7 50 sims/results/sweep_cw finalize
Rscript sims/plot_cw_typeI.R  sims/results/sweep_cw   # -> results/cw_typeI.{pdf,png}
Rscript sims/plot_cw_power.R  sims/results/sweep_cw   # -> results/cw_power{,_var}.{pdf,png}
Rscript sims/plot_cw.R        sims/results/sweep_cw   # -> results/cw_panels.{pdf,png}

# ---- 5. unknown-variance: calibration + efficiency ------------------------
Rscript sims/validate_Rfiber.R 4          # numerical R-fiber union calibrates
Rscript sims/validate_exact.R 4           # exact R-fiber union calibrates
Rscript sims/union_multiplicity.R 4       # M_eff ~ 1 (effective #regions)
```

Notes
- The plot scripts in step 4 take the **results dir as their first argument**, so
  the same commands work for any sweep dir (e.g. a re-run under another name).
- The `cw` sweep is the headline figure set; `standard` adds the k/genCov/
  unbalanced extensions. Edit the grids/tiers in `build_grid()` at the top of
  `sweep_run.R` to change parameters.

## Cluster execution

The sweep is **single-node, shared-memory** (`mclapply` over chunks) and
**checkpointed**, so it survives wall-clock limits — just resubmit the same
command and it continues.

Robust local background run (prevents sleep, survives terminal close):
```bash
tmux new-session -d -s cw 'caffeinate -i Rscript sims/sweep_run.R cw 7 50 sims/results/sweep_cw > sims/results/cw.log 2>&1'
```

SLURM (one node, many cores; resume-safe across requeues):
```bash
#!/bin/bash
#SBATCH -c 16            # cores -> pass to ncores
#SBATCH --time=06:00:00
#SBATCH --requeue
module load R
cd $SLURM_SUBMIT_DIR
Rscript sims/sweep_run.R cw $SLURM_CPUS_PER_TASK 50 sims/results/sweep_cw
```
For multi-node, partition the grid by editing `build_grid()` to emit a subset
per array task (`$SLURM_ARRAY_TASK_ID`) writing to per-task ckpt dirs, then
`finalize` over the merged `cells/` directory.
